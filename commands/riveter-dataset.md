Use the **riveter-datasets** skill to work on the dataset: $ARGUMENTS

Follow the skill instructions exactly — `get_dataset` for its columns and runs, `list_dataset_rows` for the grid, `add_dataset_rows` / `import_dataset_rows` / `update_dataset` / `update_dataset_row` for free changes, `enrich` with `dataset_id` (estimated first) to fill cells, `export_dataset` for a file. Quote the dataset `id` and any run `id` you start.
